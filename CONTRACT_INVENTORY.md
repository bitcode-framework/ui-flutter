## Notes & Caveats

- **Tier source:** P0/P1/P2 assignments are read from
  `docs/components-progress.md` (`P0 — ERP-Critical`,
  `P1 — High Value`, `P2 — Polish` tables). BcChart is tracked in a
  separate "Charts" section; BcKanbanBoard appears in
  `docs/stencil-parity-matrix.md` and `docs/codebase.md` but not in the
  tier tables, so it is listed under "Special".
- **Duplicate BcPopover:** the `adapt-poc/popover/BcPopover.contract.ts`
  file is a Phase 0 proof-of-concept with a minimal prop surface and no
  flutter hint. The production `overlays/popover/BcPopover.contract.ts`
  has the flutter hint `PopoverRoute-contract-parity` and a hand-written
  Dart widget. The PoC contract is retained for the resolver-spike
  test fixtures and should not be ported independently.
- **Stub generator:** `packages/ui/scripts/generate-flutter-stubs.mjs`
  defines a `WIDGET_MAP` of exactly 32 flutter-hinted components. It
  skips contracts without a flutter hint and refuses to overwrite
  hand-written Dart files (detected by the absence of the
  `Auto-generated by generate-flutter-stubs.mjs` header).
- **BcAdapt:** marked "NEW Tier 3" in the progress doc (a responsive
  contract primitive). It is grouped under P1 here because the P1
  Feedback/Overlays table lists it; its tier status is provisional.
- **BcChart Flutter contract (ADR-015):** The `BcChart` contract is
  ported to Dart at `lib/src/core/chart/` (not via the stub generator).
  The port mirrors `packages/ui/src/contracts/chart-option/` (the
  extracted TS contract from ADR-015 F1). The Flutter `BcChart` widget
  (`lib/src/components/bc_chart.dart`) uses `flutter_echarts` to render
  all 26 chart types via the shared `buildChartOption()` factory. See
  `doc/chart-migration.md` for the migration guide and
  `docs/adr/015-flutter-echarts-chart-strategy.md` for the full ADR.
